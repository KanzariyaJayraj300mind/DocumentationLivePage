Game Settings Menu System Plugin ​

Technical Documentation & Integration Guide | v1.0 (UE5) ​

1. Overview ​

The Game Settings Menu System Plugin is a modular and scalable settings framework built for Unreal Engine 5.

It centralizes all game settings into a single subsystem, simplifying complex systems like:

  • Video & Graphics
  • Audio (SoundMix system)
  • Input Rebinding (Enhanced Input)
  • Accessibility (Colorblind & Gamma)

Core Value ​

  • Zero-Boilerplate UI
  • Subsystem-Based Architecture
  • Data-Driven Save System
  • Real-Time Preview System

2. Installation Guide ​

Step 1: Add Plugin to Project ​

Option A: Fab Marketplace (Recommended) ​

  1. Download plugin from Fab
  2. Click Add to Project
  3. Select your project

Option B: Manual Installation ​

  1. Copy plugin folder into:

YourProject/Plugins/

  1. Your structure should look like:

YourProject/

└── Plugins/

└── Game Settings Menu System/

Step 2: Enable Plugin ​

  1. Open project in Unreal Engine
  2. Go to:

Edit → Plugins

  1. Search for:

Game Settings Menu System

  1. Enable it
  2. Restart the editor

Step 3: Required Dependencies ​

Ensure these are enabled:

  • Enhanced Input (MANDATORY)

Go to:

Edit → Plugins → Input

Enable:

  • ✔ Enhanced Input

Step 4: Compile (C++ Projects Only) ​

If using C++:

  • Right-click .uproject
  • Click Generate Visual Studio project files
  • Build the project

3. Setup Guide (CRITICAL) ​

This is required for the plugin to function correctly.

Step 1: Character Initialization ​

Setup in Character Blueprint: ​

  • Get Player Controller
  • Get Enhanced Input Local Player Subsystem
  • Add Mapping Context (IMC_AdvancedSettingsMenu)
  • Create Main Settings Widget

Important: ​

Without this:

  • Input rebinding will NOT work
  • Sensitivity system will break

Setup in Character Blueprint: ​

  • Get Player Controller
  • Get Enhanced Input Local Player Subsystem
  • Add Mapping Context (eg:IMC_AdvancedSettingsMenu)
  • Create Main Settings Widget

Important: ​

Without this:

  • Input rebinding will NOT work
  • Sensitivity system will break

Step 2: Create Main Settings Widget ​

  • Create a Widget Blueprint
  • Reparent it to:

USettingWidgetBase

This is REQUIRED.

Step 3: Configure Master Widget (Most Important Step) ​

Open Class Defaults and configure: ​

Input ​

  • Assign Default IMC
  • Fill Action Map (Jump, Move, etc.)

Audio ​

  • Assign:
    • Main Sound Mix
    • Master Sound Class
    • Music Sound Class
    • UI Sound Class
    • SFX Sound Class
    • Dialogue Sound Class
    • Ambient Sound Class

Visuals ​

  • Active Border Color
  • Inactive Border Color

Accessibility ​

  • Colorblind texture
  • Gamma texture
  • Colorblind Base Material

UI Feedback

  • Click Sound (used globally)

Step 4: Setup Key Icon Data Table

Steps: ​

  1. Create Data Table → Struct: FKeyIconData
  2. Add rows:
    • Key (FKey)
    • Icon (Texture)
    • Image Size

Result: ​

  • Keys display as icons instead of text

Step 5: Assign Sound Classes to Audio Assets ​

Example: ​

  • Music → SC_Music
  • UI Click → SC_UI
  • SFX → SC_SFX

Important: ​

If not assigned:

  • Volume sliders won’t work

Step 6: Ensure Post Process Volume Exists ​

Required for:

  • Colorblind mode
  • Gamma control

Setup: ​

  • Add PostProcessVolume in level
  • Enable: Infinite Extent (Unbound)
  • Add PostProcessMaterial to MI_ColorCorrection

4. Core Architecture ​

USettingsManager (Subsystem) ​

Central system handling everything.

Features: ​

  • Save / Load system
  • Apply settings pipeline
  • Input rebinding system
  • Audio mixing system
  • Accessibility system
  • Tooltip system

Apply Pipeline ​

ApplyAllSettings()

├── ApplyVideoSettings()

├── ApplyGraphicsSettings()

├── ApplyAudioSettings()

└── ApplyControlSettings()

USettingWidgetBase ​

Acts as:

  • UI → Backend bridge
  • Handles:
    • Selection
    • Tooltip
    • Data injection

5. Systems Breakdown ​

Video Settings ​

  • Resolution
  • VSync
  • FPS Limit
  • Window Mode
  • FOV
  • Motion Blur
  • Gamma / Brightness
  • Anti-Aliasing

Graphics System ​

  • Scalability presets
  • Custom overrides
  • Auto-sync system

Audio System ​

  • Uses SoundMix
  • Real-time preview
  • Volume normalization (0–100 → 0–1)

Input System (Advanced) ​

  • Runtime IMC duplication
  • Safe rebinding system
  • Supports Primary + Secondary keys

Accessibility ​

  • Colorblind modes
  • Gamma calibration
  • Material-based implementation

Real-Time Testing System ​

Users can:

  • Test settings
  • Confirm
  • Revert

Tooltip System ​

  • Global tooltip widget
  • Auto updates on selection
  • Plays UI sound

  • Set Tooltip data for individual widgets with or without images.
