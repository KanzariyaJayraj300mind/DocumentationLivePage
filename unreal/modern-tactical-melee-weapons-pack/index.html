**Modern Tactical Melee Weapons Pack – UE **

The Modern Tactical Melee Weapons Pack is a semi-realistic, game-ready asset collection designed for UnrealEngine. It provides a set of high-quality melee weapons that can be quickly integrated into games, simulations, VR experiences, and real-time applications.

Created with performance and flexibility in mind, this pack includes 4 optimized models and prefabs built for real-time use. The assets are suitable for PC, console, mobile, and VR platforms, making them ideal for a wide range of interactive projects.

Key Features ​

  • 4 Ready-to-Use Models
  • Easy to customize and integrate
  • Semi-realistic visual style
  • Optimized for real-time performance
  • Suitable for multiple platforms and project types

Included Content ​

  • Push Dagger
  • Folding Knife
  • Tactical Knife
  • Tomahawk

Target Use ​

  • Game Development
  • Cinematics & Animation
  • VR Experiences
  • Mobile Applications
  • PC & Console Projects

Technical Details ​

  • Total Assets: 4 models and prefabs
  • Style: Semi-realistic, low-poly
  • Texture Sizes: 4096×4096
  • Optimized Low-Poly Geometry: Ranges from 7000 to 17,000 triangles per mesh
  • Platform Support: PC, Console, Mobile, VR

Perfect for creating combat systems, action gameplay, and immersive environments, the Modern Tactical Melee Weapons Pack offers a fast and efficient solution for developers looking to integrate high-quality weapon assets into Unity projects.
