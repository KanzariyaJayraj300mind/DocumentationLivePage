Advanced AI Turret Framework

Description ​

  • The Advanced AI Turret Framework is perfect for games with multiple robot AI enemies. It is built entirely in C++ and is easy to set up.
  • Simply set the parameters for your game, drag and drop the Turret, and it will work.
  • For AI detection of your pawn, the Player Controller and Character must be derived from our Custom Player Controller and Custom Player Character classes.
  • Or implement the IGenericTeamAgentInterface properly, Team Agent Interface Setup Guide in both their controller and character classes.
  • And add “AIPerception Stimuli Source”

And also make sure you’ve registered the required sources for senses too.

  • This allows you to create AI teams that can fight each other.

For Setup, refer to the 10-point setup guide.

Setup Guide ​

Installation Guide ​

  • Install the Plugin from Epic Launcher
  • Open your project
  • In the Edit menu, Select Plugins

  • Find and Enable the AdvancedAlTurretFramework Plugin

  • Open the Content Browser

  • Open the Settings option in Content Browser and check on the Show C++ Classes and Show Plugin Content.

Turret Base Body Setup Guide ​

  • Go to the AdvancedAlTurretFrameworkContent/AITurret/Blueprint

  • Drag and drop any turret with an attachment into the world, then set the parameters in the Turret Settings section of the details panel.

  1. Base Stats of the Turret
    1. Turret Speed: Defines the Movement speed of the Turret
    2. Wait Time: The Time to wait after reaching the patrol point
    3. Acceptable Radius: Fixed Distance added to the threshold between AI and the Target location. AI will stop following the player as long as it’s in an Acceptable radius
    4. Total Health: Max health of the Turret
  2. Turret Movement:
    1. Movement Mode:
      1. Mobile: Can move around and follow the Target
      2. Mounted: Stationary Turret
        1. Fixed-Fire Mode: This mode emphasizes the Turret’s fixed direction, indicating that it will only fire enemies within its predefined field of vision.
        2. Tracking-Fire Mode: This mode highlights the Turret’s ability to track and follow enemies, ensuring that it keeps them in sight and continuously engages.
    2. Movement Behaviour:
      1. Patrol Type: Set the locations of patrol points in the “Array of Points” vector.
        1. Sequence: Turret will move around the patrol Points in the sequence it was assigned to
        2. RandomPoints: Turret will move around the Patrol Points in a random order

      1. Radius Type: The turret will patrol in the given radius from a given center. When following the target, if the target goes out of the defined radius, the turret will try to get close to the Target while staying within the radius.

  1. Search Center: The center of the Search area, using this location Turret will patrol the area of the defined radius.
  2. Offset: When the player leaves the search area, the Turret adjusts its acceptable radius to get as close as possible without being too near the border. The Offset value keeps the Turret slightly away from the edge, ensuring it's not too close if the player is just outside.
  3. Search Radius: Radius of the Patrol Area of the Turret
      1. Investigate Type:
  • The movement of the Turret in this Movement Behaviour is similar to the Radius search, though the turret will come out of the radius when following the Target, and the Turret can hear sounds in this movement behavior only.
  • Upon detecting the sound Turret will go to that position and will patrol n times around the area where the sound was detected, and after that it will go back to its usual patrolling.
  • If the position is unreachable, it will ignore the detected sound.
  • The sound can be made by calling the report Noise event in the Target.
  • If the value of loudness is too much, it can be detected by the Turret even if it's outside its hearing range. If the loudness value in the Report Noise Event is high, it can be heard by the AI even outside its hearing range. Try to keep it around 1-5.

Set the Hearing-related properties in the AI Perception category.

Search Center and Search Radius are the same as the ones in Radial Search.

  1. AI Perception Settings:

  1. Hearing Range: The range in which AI can hear noise
  2. Radius: The radius of the area in which the Turret will patrol at the location of the noise.
  3. Search Count: The number of locations the turret should patrol near the location of the noise.

The above properties will only be visible in the Investigate Type Movement Behaviour.

  1. Sight Settings
    1. Sight Radius: Maximum sight distance to notice the target.
    2. Lose Sight Radius: Maximum sight distance to see the target that has already been seen.
    3. Peripheral Vision Half Angle Degrees: How far to the side AI can see, in degrees. The value represents the angle measured with the forward vector, not the whole range.

Turret Attachment Setup Guide ​

  • After setting the Base parameters, select the Attachment Component from the hierarchy to set its parameters in the details panel.

To add any attachment to the BP Turret, click on the Add button in the components window.

Search for the attachment you want to add and click on it to add it.

Make sure the attachment component is the child of the skeletal mesh of the Turret.

Now, attach the mesh of attachment with that of the Turret

In the details panel, in the socket section.

Set the Parent socket to “attach_root” bone to directly attach the component.

There are a total 6 Types of Attachments:

  • Gun Attachment
  • Rocket Launcher
  • Grenade Launcher
  • Bomber
  • Laser Shooter
  • Mine Placer

There are some common properties among the attachments:

  • Projectile Actor: The actor spawns when firing. This property is only visible in the Gun, Grenade launcher, and Rocket Launcher Attachments.
  • Base Effects: Niagara Particles VFX for muzzle flash in Attachments, excluding bomber and Mine Placer.
  • Attachment Properties:

    • Fire Rate: Rate of fire of the Turret.
    • ShootTrace Channel: The turret will do the trace on the collision channel set here.
    • Initial Delay: Time to wait when shooting the Target for the first time until it's in sight.
    • Shooter Socket Name: The socket name at the bone from where the projectile/ laser beam will spawn.
    • Indicator Parameter Name: Name of the parameter of the Material Instance for the Indication lights.
    • Attack mode:
      • Lock on: Locks the target and will keep on attacking it until it's dead or unable to be detected by the turret.
      • Closer to AI: The Turret will start attacking those who are closer to the turret.
      • Attacker Priority: The turret will prioritize the targets that are damaging the turret.
  • Projectile Properties:

    • Projectile Lifespan: Lifespan of the projectile.
    • Should Override Projectile: When set to true, you will be able to change the base properties of Projectiles from here.
    • Projectile Speed: Speed of the projectile in cm/s.
    • Projectile gravity Scale: Gravity Multiplier to be applied to the projectile.
    • Note: To allow the projectile to interact with environment assets such as doors, walls, etc. Make sure to check “Generate Overlap Events ” in the collision section, and also set the Collision Preset to “Default”.
  • Damage Properties:
    • Damage Type Class: The class that helps the turret to deal special damage i.e., Fire, poison.
    • Damage: The Amount of Damage to be dealt in a single hit.

The following properties are only accessible in Attachments that deal damage through Explosions.

    • Damage Inner Radius: Radius of the full damage area from the origin.
    • Damage Falloff: Falloff exponent to be applied when dealing damage radially.
    • Minimum Damage: Minimum amount of Damage to be done by the turret.
    • Damage outer Radius: Radius of the minimum damage area from the origin.
  1. Gun Attachment:

  • Gun Mode:
    • Single:

      • WaitTime: Time to wait before firing the next bullet.
      • Magazine Size: Number of bullets in a magazine.
      • Reload Time: Time taken to reload.
    • Burst

      • The number of bullets to shoot in a single burst.
    • Auto

      • How far the bullet can travel in cms.
  1. RocketLauncher:

  • These two properties are exclusive to the Rocket launcher only, and ShouldOverride Projectile should be true to access these in the details panel.
  • isHoming: When True, the projectile will follow the target until it expires or hits something.
  • Homing Magnitude: The accuracy of the Homing Rocket.
  1. Laser Shooter:

  • Laser beam: Particle System of Laser beam to visualize laser shooting
  • Base Damage: Base Damage is to be dealt at the First hit of the beam.
  • Laser Damage Type: This will decide the type of damage you want to deal to the player.
    • Constant Damage: Constant Damage at every hit.

    • Rate of Damage Over Time: Damage accruing at a compound rate.
      • Damage Rate: Rate of Damage to be increased over time.
      • Max Damage: The damage will keep on increasing until it is equal to that of Max Damage.

    • Damage Curve: It will use a curve to deal the damage at that given time.
      • Damage Curve: The float curve graph is used to calculate the amount of damage at a specific time.

    • Laser Range: Indicates the current range of the laser. This value is visible in the editor for reference, but can only be modified at runtime using the provided methods. These methods are accessible both via Blueprints and in C++.
      • Enabled: When enabled, the laser's range will be limited. The specific range can be adjusted dynamically at runtime using the appropriate methods.
      • Disabled: When disabled, the laser will operate without a range limit, effectively allowing it to extend indefinitely or until it hits an obstruction, depending on the system's behavior.

  1. Bomber:

The bomber will rush towards the target when it sees one and will try to make contact with the target. When the bomber makes contact after some time, the bomb will explode.

  • Timer: The time taken to explode after coming in contact with the player. If set to 0, the bomber will instantly explode.
  • The rest of the properties are the same as those mentioned in the Damage Properties section above.

There’s a collision sphere attached to the attachment component. If that sphere overlaps with the target, the timer will start ticking and it will explode after a certain time. The collision sphere properties can be found in the base properties category inside Attachment Settings.

  1. Mine Placer:

Mine Placer will not be able to see the player, its only job is to place a certain number of mines in the assigned area. When AI is done placing all the mines, it will start roaming until a mine gets destroyed. Mine Placer will roam around the area as if it’s patrolling, and whenever it reaches the patrol point, it will spawn the defined number of mines and spread them out, and then move to the next location. The Damage Properties of the Mine are the same as the other damage properties of explosives. Currently, there are only two types of mines created.

  • Proximity Mine: If the player is at a distance of a certain radius from the mine, it will explode.
  • Land Mine: If the player comes in contact with the mine, it will explode.

  • Mine Count: Number of mines to be spawned at once.
  • SpawnZ: Offset Position in the Z Axis of the Attachment from where the mine should be thrown.
  • Throwable Actor: Blueprint Actor reference of the mines.
  • Total Mine: Total Mine count that should be placed by the mine placer.
  • This is how to set up the Turret in your level.
  • You can create the Projectile Actors that you want, but they should be derived from the ProjectileParent Class same goes for the Mines they are derived from the ThrowableParent Class.
  • It is advised to add a custom collision trace channel through the project settings so that all the damage dealt by the turret can be done using that, and it doesn't get interrupted by any other collision.

Collision Channel Setup Guide ​

  • Note: Either create a new Trace Channel or use a previously created Trace channel, but it is necessary to add that channel in variable

ShootTrace Channel under the AttachmentComponent.

And set the trace channel’s response to Block in Character’s mesh Component. Without this Turret won’t deal damage to the Player.

  • To add a custom Trace channel, go to the Project Settings from the Edit Menu.

  • After that, select the Collision option from the categories on the right, you can find it under the Engine Section.

  • Then click on the New Trace Channel button to create the new trace channel.

  • Set its default collision response for other objects, and you are good to go. Use this newly created Trace in the ShootTrace Channel variable in the Attachments, and set the collision response of this channel accordingly in your character. The process is the same for creating a new Object Channel. NOTE: NE_BulletTrail and NE_LaserBeam Niagara emitter works on collision, so don't forget to change the trace channel there too.
