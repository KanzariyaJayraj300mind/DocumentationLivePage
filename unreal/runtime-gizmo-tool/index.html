Runtime Gizmo Tool ​

1. Introduction ​

The Runtime Gizmo plugin provides an in-game transformation tool for Unreal Engine that allows users to move, rotate, and scale actors/components at runtime.

It enables editor-style manipulation inside gameplay, making it ideal for transforming objects at runtime.

The system supports:

  • Translation (Move) , Rotation , Scaling of objects in level

  • Axis-based manipulation

  • World and Local space switching

  • Multi selection and cloning

  • Value based snapping

  • Blueprint integration

2. Installation ​

  1. Add the plugin to your project (Engine or Project Plugins folder).

  2. Open Edit → Plugins.

  3. Enable Runtime Gizmo.

  4. Restart the editor.

3. Required setup ​

3.2 Implementation ​

Functions to implement ​

To use the Runtime Gizmo, the following functions must be implemented:

    • Show and use gizmo

      • Show Gizmo and Start Transform Process – Begins the transformation operation when interaction starts (e.g mouse press)

      • Stop Transform Process – Ends the transformation operation when interaction stops (e.g mouse release).

    • Cloning

      • To start cloning, set bIsCloning in the Runtime Gizmo Component to true.

      • To stop the cloning process, set bIsCloning to false.

    • Multi Selection

      • To enable multi-selection, set bIsSelectingMultipleObjects in the Runtime Gizmo Component to true.

      • To disable multi-selection, set bIsSelectingMultipleObjects to false.

    • Delete selected objects
      • To delete selected objects call DeselectAll(Destroy Selected = true) to destroy all the selected objects, If Destroy Selected is set to false, the actors will only be deselected and not destroyed.

    • Snap Selected objects to ground
      • To snap selected objects to the ground call Snap Selected Objects to Ground

Functions to override ​

    • Should Select Object (Optional) : Used to determine whether a specific Actor or Component is eligible for selection and Gizmo interaction.

      • This function allows you to:

        • Control which objects can receive the Gizmo

        • Exclude specific actors or components from being selectable

        • Implement custom filtering logic (by class, tag, interface, etc.)

      • Return value behavior:

        • Return True – The object is allowed to be selected and can use the Gizmo.

        • Return False – The object is excluded from selection and will not receive the Gizmo.

Override this function to implement custom selection rules for your project.

    • On Selection Change (Optional – Implement inside Runtime Gizmo Component) : Called automatically whenever a component or actor gains or loses selection focus.
      • Parameters:

        • Component – The affected component.

          • If selection is Actor-based, this will be the actor’s Root Component.

          • If selection is Component-based, this will be the selected component itself.

        • Is Component Based

          • True → Selection is component-based.

          • False → Selection is actor-based.

        • Selected – Indicates the current selection state.

          • True → The object has gained focus (selected).

          • False → The object has lost focus (deselected).

This event can be overridden to implement custom focus behavior such as:

  1. Highlight effects

  2. UI updates

  3. Outline toggling

  4. Sound feedback

    • It is especially useful for actors or components that do not implement the GizmoFocus interface.

Interface ​

    • Gizmo Focus Interface : The Gizmo Focus interface is used to define custom per-actor behavior when an actor or its component gains or loses selection focus(This interface is automatically triggered by the Runtime Gizmo Component.).

      • It allows you to implement custom logic such as:

        • Highlight effects

        • Material changes

        • UI updates

        • Sound feedback

        • Custom visual indicators

    • Whenever an actor or component receives or loses focus, the corresponding interface function is called automatically.

    • Use this interface when you want actors to handle their own focus behavior instead of relying on the OnSelectionChange event.

4. Demo content ​

The plugin includes a complete working example located in:

Plugins → Runtime Gizmo Content → RuntimeGizmo → Demo (Enable Show Plugin Content if not visible)

The Demo contains:

  • A fully configured Player Pawn with all required input bindings

  • Actor containing description of all the available functions

  • A ready-to-use UI for mode switching and snapping

  • Transform mode switching (Move / Rotate / Scale)

  • World / Local space switching

  • Value based snapping controls

  • Cloning and Multi Selection

Note : The Runtime Gizmo does not automatically handle input. You must use the included Demo Player Pawn or implement similar logic in your own Pawn or Player Controller.

For complete description of all Runtime Gizmo functions, refer to the BP_InfoActor located at: Plugins → Runtime Gizmo Content → RuntimeGizmo → Demo → BP_InfoActor

5. Runtime Gizmo Component Overview ​

Properties ​

    • Current Transform Space Type : Determines the coordinate space used by the Gizmo for transformations (Can also be modified at runtime).
      • This defines whether the Gizmo operates in:

  • World Space – Transformations are aligned with the world axis.

  • Local Space – Transformations follow the selected actor’s local axis.

    • Gizmo Placement : Determines how the Gizmo is positioned when multiple actors are selected.

      • On First Selection – The Gizmo appears at the location of the first selected actor/component.

      • On Last Selection – The Gizmo appears at the location of the most recently selected actor/component.

** **

    • Current Gizmo Transformation : Defines the active transformation mode used by the Runtime Gizmo Component (Can also be modified at runtime).

      • None – Selection mode only. Allows selecting objects without applying any transformation.

      • Location – Enables movement (translation) of selected objects.

      • Rotation – Enables rotation of selected objects.

      • Scale – Enables scaling of selected objects.

    • Force Component Mobility – Determines whether the Gizmo should override component mobility settings.

      • True – Components that are not set to Movable will automatically have their mobility changed to Movable to allow transformation.

Warning : The original mobility setting is not restored after transformation.

      • False – No transformation will be applied to components that are set to Static or Stationary.

    • Toggle Selected in Multi Selection – Determines whether clicking an already selected object will deselect it or not in multi select.

      • Enabled (True) – Clicking a selected actor will remove it from the current selection set.

      • Disabled (False) – Clicking a selected actor will keep it selected.

Functions ​

The Runtime Gizmo Component exposes multiple Blueprint callable functions for selection, transformation, snapping, cloning, and multi-selection management.

For a complete and detailed explanation of all available functions, refer to the BP_InfoActor located at:

Plugins → Runtime Gizmo → Content → RuntimeGizmo → Demo → BP_InfoActor

(Enable Show Plugin Content if not visible.)
