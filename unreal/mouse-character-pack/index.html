Mouse Character Pack

The Mouse Character Pack is a semi-realistic, game-ready character asset collection designed specifically for Unreal Engine. It provides a set of high-quality rat characters that can be quickly integrated into games, simulations, and real-time applications.

Built with performance, scalability, and flexibility in mind, this pack includes optimized character meshes and blueprints created using a clean and efficient workflow. The assets are suitable for PC, console, and mobile, making them ideal for real-time projects across a wide range of use cases.

Key Features ​

  • 5 Ready-to-Use Character Meshes
  • Clean and organized asset structure and naming conventions
  • Semi-realistic, optimized visual style
  • Optimized for real-time performance
  • Easy drag-and-drop Unreal Engine Blueprints
  • Compatible with multiple platforms and project types

Included Content ​

  • Cheddar_Boss
  • Chilltail
  • Ironpaw
  • Dr. Squeakstein
  • Whisker_Holmes

Target Use ​

  • Game Development
  • Cinematics & Animation
  • Mobile Applications
  • PC & Console Projects

Technical Details ​

  • Total Assets: 5 Static Meshes & Blueprints
  • Engine: Unreal Engine (UE 5.3+ compatible)
  • Style: Semi-realistic
  • Texture Sizes: 2048×2048
  • Optimized Geometry: Approximately 10,000 to 44,000 triangles per mesh
  • Platform Support: PC, Console, Mobile

Perfect for creating stylized environments, storytelling scenes, or gameplay involving small creatures, the Mouse Character Pack offers a flexible and performance-friendly solution for Unreal Engine developers.

NOTE: This pack contains static mesh, not a rigged skeleton mesh.
